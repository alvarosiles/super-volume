Super Volume
Extensión para Google Chrome
Web Audio API · GainNode

Sube el volumen de cualquier pestaña hasta 600%

Amplifica el audio de la pestaña activa usando la Web Audio API del propio navegador, sin tocar en ningún momento el volumen del sistema operativo. Funciona en cualquier sitio con video o audio.

Ver en GitHub Política de privacidad

Qué hace

Hasta 600% de volumen

Slider animado de 0% a 600%, con el porcentaje visible en tiempo real.

Recuerda por sitio

Guarda el volumen preferido por dominio y lo reaplica automáticamente.

Reset y Mute

Un clic para volver a 100% o silenciar sin perder tu ajuste guardado.

100% local

Sin llamadas de red, sin cuentas, sin analítica. Todo ocurre en tu navegador.

Instalación en modo desarrollador

  1. Descargá o cloná el repositorio desde github.com/alvarosiles/super-volume.
  2. Abrí Chrome y andá a chrome://extensions.
  3. Activá el Modo desarrollador (interruptor arriba a la derecha).
  4. Hacé clic en Cargar descomprimida y seleccioná la carpeta del proyecto.
